# Data & ML Projects

A portfolio of data and AI projects (work in progress). The goal is to practice and learn by building, focusing on understanding the methods rather than polished products.

Skills learned/revisited:
- Pandas
- Combining and cleaning data
- Machine learning basics with **scikit-learn**
- Evaluating ML models

## 📂 Projects

- Project 0 – **Pandas Recap**  
  A folder for revisited python pandas.

- Project 1 – **Data Analysis and ML Basics**  
  A folder for data analysis and machine learning basics with **scikit-learn**.

- Project 2 – **Energy Load Prediction**  
  A small project that trains a model on **real-world energy consumption and weather data** to predict the **load** given certain weather conditions.
